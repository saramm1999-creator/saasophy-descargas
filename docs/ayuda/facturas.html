SaaSophy Facturas

Las facturas de tus proveedores, leídas solas · 450 € pago único · Comprar

1. Instálalo

  1. Después de pagar te llega un email con tu clave de licencia y los enlaces de descarga (también los ves en la página de tu compra).
  2. Descarga el instalador de tu sistema: Windows · Mac.
  3. Windows: abre el archivo. Si sale «Windows protegió su PC», pulsa Más información → Ejecutar de todas formas.
  4. Mac: abre el archivo .dmg y arrastra el programa a Aplicaciones. Si al abrirlo dice que es de un desarrollador no identificado, haz clic derecho sobre el programa en Aplicaciones, elige Abrir y vuelve a pulsar Abrir (o ve a Ajustes del Sistema → Privacidad y seguridad y pulsa Abrir igualmente). Solo pasa la primera vez.

2. Primer arranque

  1. Pega tu licencia.
  2. Pega tu clave de Claude (console.anthropic.com → API Keys; añade 5 € de saldo, dan para unas 250 facturas).
  3. ¿Usas Holded? Pega tu clave de API de Holded (en Holded: Ajustes → API → Generar nueva clave, con permiso para Compras, Contactos e Impuestos). Si no, sáltalo.

3. Úsalo

  1. Arrastra las facturas de tus proveedores (PDF, JPG o PNG), todas a la vez.
  2. Las bien leídas (✅) se suben solas a tu Holded como facturas de compra, con el proveedor (lo crea si no existe), el IVA, la retención y el PDF adjunto.
  3. Las dudosas (⚠️) esperan: revísalas y pulsa «Revisada, subir».
  4. Siempre puedes pulsar «Descargar Excel» para tu gestoría.

Actualizaciones

El programa se actualiza solo: al abrirlo te avisa si hay versión nueva.

¿Algo no funciona?

En el programa, abre Ajustes y pulsa «Enviar informe a soporte»: se abre tu correo con un informe técnico (sin datos de tus clientes) dirigido a hola@saasophy.online. Cuéntanos qué pasó y te respondemos lo antes posible.
